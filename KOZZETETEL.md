# AlexFPV Studio közzététele (GitHub Pages, ingyen)

Ugyanúgy megy, mint a FoodShare-nél.

1. https://github.com → jobb fent **+ → New repository**
   - Repository name: `alexfpv-studio`
   - **Public**, pipáld be: **Add a README file** → **Create repository**
2. **Add file → Upload files**
3. A Finderben nyisd meg a `Projektek/Arajanlat` mappát, jelöld ki **az összes fájlt** (a `pdf.js`-t is!), és húzd be a böngészőbe.
4. Lent: **Commit changes**.
5. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, mappa: **/ (root)** → **Save**
6. 1–2 perc múlva megjelenik a cím: `https://FELHASZNALONEV.github.io/alexfpv-studio/`

## Telefonon appként

- **iPhone (Safari):** nyisd meg a címet → Megosztás gomb → **„Főképernyőhöz adás”**
- **Android (Chrome):** nyisd meg a címet → megjelenik a **„📲 Telepítés appként”** gomb, vagy menü → **„Hozzáadás a kezdőképernyőhöz”**

## Fontos tudni

- Az áraid és tételeid **csak azon az eszközön** vannak elmentve, ahol beírtad őket (localStorage). A gépen és a telefonon külön kell beállítani.
- **PDF készítése:** „📄 PDF mentése / küldése” gomb. Telefonon megnyílik a megosztás menü (Mentés a Fájlokba, WhatsApp, Mail…), gépen letöltődik a PDF. A „🖨️ Nyomtatás” gomb csak gépen megbízható.
- **Frissítés után telefonon:** ha a régi változat jön be, zárd be teljesen az appot, és nyisd meg újra (vagy töltsd újra kétszer).
- A GitHub-os cím nyilvános, de az áraid nem kerülnek fel sehova: azokat csak a te böngésződ tárolja.

**Frissítés később:** **Add file → Upload files**, és húzd be a megváltozott fájlokat.
